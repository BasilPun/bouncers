# Bouncers, a SDEV 301 assignment on OOP in C++

![gameplay](bouncersGIF.gif)

TO PLAY: Press X to spawn birds!

In my version of bouncers, instead of spawning yellow balls, it spawns a flying bird that zooms through the screen in a left/right orientation depending on which direction it is heading towards. On top of that, after each wall hit, the bird drops by 10% in size till it eventually.. disappears!
